## 한 일

- 글이 안 보이던 원인 둘: (1) 일정 칸이 단추라 글을 세로 가운데로 내렸고, 표시(점·네모) 뒤에서 글이 다음 줄로 밀려 짧은 칸에선 잘림. (2) 하루를 한 화면에 맞춘 한 시간 높이(약 30px)가 너무 낮음. → 글을 칸 맨 위부터, 표시는 글 옆에. 한 시간 높이 기본값 = 가장 짧은 일정에도 글 두어 줄이 들어가는 높이(하루가 한 화면보다 크면 위아래로 굴림).
- 두 손가락 벌리기·오므리기(트랙패드는 ctrl+휠)로 한 시간 높이 확대·축소: 하루 한 화면 ~ 한 시간 160px, 손가락 가운데 시각이 제자리. 이 기기에 기억.
- 좌우: 보이는 날 앞뒤로 날을 더 그려 두고 브라우저 굴리기(날 칸에 붙음)로 넘김. 멈추면 그 날로 달력을 옮기고 자리만 가운데로 되돌림(화면은 그대로). 화살표도 부드럽게 굴림. 날짜 줄은 위에, 시간 축은 왼쪽에 붙어 있음.
- 일정 끌기: 한 번 누르면 고르기(테두리 + 안내 한 줄), 고른 일정만 몸통 끌기 = 옮기기, 아래 끝 = 길이. 한 번 더 누르면 자세히. 빈 칸 누르기·Esc = 놓기. 고르지 않은 일정은 굴리기만(손가락 길게 누르기 없앰).
- 메모 모두 지우기: 메모 칸 '모두 지우기'(확인 창) → 서버 새 주소 `DELETE /api/memo { confirm: true }`(내 메모만, 메모로 만든 일정·할 일은 남음).
- 고친 김에: `time.js dayIndex`가 7일 넘는 칸을 늘 '밖'으로 봐서 더 그려 둔 날에 일정이 안 그려지던 것 — 날 수를 받게 함.
